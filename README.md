## 1.SDK

Мини-SDK и приложения для камеры `HIK/HJK FPGA UVC Camera` (VID:PID `2bdf:0102`):

- захват 16-бит Y16 (640×512)
- свой пайплайн рендеринга (destripe + TNR + PE + DDE + палитры)
- измерение температуры
- обновление прошивки

**Быстрый старт:** [`1.SDK/README.md`](1.SDK/README.md)

**Документация:**

- [`1.SDK/docs/LIFECYCLE.md`](1.SDK/docs/LIFECYCLE.md) — жизненный цикл и обработка ошибок
- [`1.SDK/docs/ARCHITECTURE.md`](1.SDK/docs/ARCHITECTURE.md) — структура модулей, потоки, данные
- [`1.SDK/docs/PROTOCOL.md`](1.SDK/docs/PROTOCOL.md) — реверс HCUSBSDK: карта команд, прошивка, крипто

## Железо

| Параметр | Значение |
|---|---|
| Модель | FPGA UVC Camera |
| VID:PID | `2bdf:0102` |
| Разрешение | 640×512 |
| Формат | Y16 (16 бит, 25 fps) |
| Прошивка | APP 20022 BUILD 20251015 |
| HW | FPGA 260001 BUILD 20250728 |
| SN | EA6334673 |

## Требования

- Ubuntu / Debian (x86_64), X11 или XWayland
- g++ C++17, OpenCV 4.x
- Вендорский SDK (в `~/sdkreverse/x86_64/lib/`):
  `libHJKUSBSDK.so`, `libHCUSBSDK.so`, `libIRSDK.so`, `libhpr.so`

## Лицензия

Вендорский SDK — собственность производителя, в репозиторий не входит.
Код проекта — свободный.
